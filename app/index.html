Sources & Method

Trophy data

The trophy list is the official PlayStation 5 trophy list for Grand Theft Auto VI — 55 trophies — as published via Exophase. Trophy names, descriptions and grades (platinum, gold, silver, bronze) are reproduced exactly as the official text; they are not edited, paraphrased or re-graded here.

Guides, with sources cited

Every guide in this app is original editorial writing, derived only from the official description of its own trophy. No walkthrough text has been copied from any other guide or site. Where an official description names no location, step or number, the guide deliberately stays at the level the description supports instead of inventing specifics — a guide that guesses would be worse than one that is honest about its source. Each trophy's detail view carries its citation line, and every guide closes with its source.

How trophies are classified (kind)

  • Story — the description asks you to complete a named mission, chapter or mission-strand finale.
  • Collectible — the description is an all-of-them checklist: every spot, set, gang, property or catalogue to complete.
  • Cumulative — the description sets a numeric total reached by repeating an action (250 stunts, $250,000 laundered, 50 challenges).
  • Skill — the description demands a specific feat or standard: a win, a gold medal, a stealth robbery, five takedowns in one activation.
  • Exploration — the description is about covering the state of Leonida or sampling everything it offers.
  • Completion — overall completion milestones, including the platinum itself.
  • Special — one-off moments whose descriptions are hints or reactions rather than tasks.

Missable flags — cautious, and based on the descriptions

A trophy is flagged missable only when its official description, or the structure of the list around it, implies a one-time event: a unique encounter for a named character, a single departure at a location the list ties to one story mission, a one-off scripted escape. Each flag states its basis in the trophy's detail view, and each is labelled as flagged cautiously from the description alone — not confirmed. If a description does not support a flag, the trophy is not flagged, however suspicious it looks.

Your progress

The tracker runs entirely in your browser: ticks are stored in localStorage on this device, nothing is uploaded, and the app makes no network requests. Export downloads your progress as a JSON file; import reads it back, on this or another device.
